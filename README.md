# Anuncios Gonty

Repositorio privado para gestionar los anuncios de la app Gonty.

## Archivos

- `anuncios.json` - Control maestro de anuncios
- `INSTRUCCIONES.md` - Guía de uso

## Flujo

1. Subir video a Odysee (o YouTube)
2. Editar anuncios.json con la URL de Odysee
3. Git push
4. La app refleja los cambios en máximo 7 días

## Plataformas

- **YouTube** → Videos normales
- **Odysee** → Videos polémicos/adultos
- **GitHub** → JSON de control (este repo)

## Anonimato

- Repo privado en GitHub
- Cuentas anónimas en YouTube/Odysee
- VPN al editar
- Email alias en todas las plataformas
